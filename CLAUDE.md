# FrameFoundry engineering contract

Read README.md, docs/PRODUCT.md, docs/ACCEPTANCE.md and docs/CLAUDE_START.md first.
This is a generic media application. Never hard-code a client into models or exports.
Keep changes in a feature branch and deliver reviewable PRs with test evidence.
Do not overwrite originals. Do not upload media by default. Use argument arrays
for subprocesses. Preserve provenance and truthful status labels.
Never present heuristic measurements as verified creative judgments.
Start by auditing existing code; do not assume the scaffold is production-ready.
Deliver in milestones. Document limitations, failures and untested platforms.
Do not auto-merge. The supervising assistant will cross-reference requirements,
inspect code and test evidence, and request corrections before release.
